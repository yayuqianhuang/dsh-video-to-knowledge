# Release v0.1.12 · 字幕信号节点

## 这一版解决什么

两轮真实全流程（`BV1j8ede8EKk` 11 集 / `BV1bMLq64Eui` 10 集）踩出来的三个字幕坑，全部做成链里的信号节点：

| 坑 | 症状 | 节点 | 判据 |
|---|---|---|---|
| 接口不稳定 | 同一分 P 多轮探测结果不同，单次"没有字幕"不可信 | `probeSubs` | 多轮采样（默认 8 轮），只保留 max(end) 落在本 P 时长 85%–115% 的轨道 |
| 字幕串台 | 时长对得上、内容却是另一支视频（实测混入 iPhone 评测、靶场 vlog），旧判据按覆盖率 ≥60% 全绿放行 | `auditTranscript` | 按章关键词命中：≥2 判 ok、1 判 weak、0 或命中异物词判 mismatch |
| 无字幕/串台 | 需要兜底又不想落音频 | `asrFallback` | 本地转写，音频只落临时目录、转完即删；解码走 ffmpeg→numpy，绕开 faster-whisper 内部 PyAV 的 `TypeError` |

`transcriptGate` 相应改为「覆盖率 + 内容」双判据；`prepareBail` 改为**只有 ASR 也失败才早停**。

## 新增命令

```bash
python pipeline/vk_chain.py probe    --video-id BV1xx… --rounds 8   # 0=有轨 / 5=无轨
python pipeline/vk_chain.py audit    --video-id BV1xx…              # 0=内容对 / 4=串台
python pipeline/vk_chain.py asr      --video-id BV1xx… --download   # 0=成功 / 6=缺依赖 / 7=失败
python pipeline/vk_chain.py template --prompt "把这个视频…参考书（简介+目录+正文+附录）：<链接>"
python pipeline/vk_chain.py bookplan --video-id BV1xx…
```

## 提示词模板进链

`templateParse` 识别「把这个视频（标题）沉淀成知识卡，并整合知识卡形成一本包含视频中所讲解所有概念的参考书（简介+目录+正文+附录）：链接」：

- 抽出视频号 / 链接 / 标题；
- 识别到四段结构即 `deliverable=book`，`sections=[简介,目录,正文,附录]`；
- 后面接 `bookPlan`，只给编/章骨架，正文一个字不代写。
