# Release v0.1.14 · 缺依赖：探测做厚 + 引导给准

## 这一版解决什么

用户没装 yt-dlp 时，以前的表现是：**跑到 `vk_prepare` 才失败**，报一句 `pip install -U yt-dlp` 就结束。这一版把它拆成两件事，都不替你装。

### ① 探测做厚：多一档「模块兜底」

`yt-dlp` 的查找顺序变成：

```text
--ytdlp / $VK_YTDLP  →  PATH  →  常见安装路径  →  python -m yt_dlp
```

最后一档救的是这个极常见的情况：**`pip install yt-dlp` 装过了，但 `Scripts` 目录不在 PATH**。只要模块在，`python -m yt_dlp` 一定能跑。

- 新增 `vp.ytdlp_cmd()`，返回命令前缀（`[exe]` 或 `[python, "-m", "yt_dlp"]`）；
- `vk_chain` 的元数据 / 字幕 / subs 探测 / doctor 四处调用全部改走它；
- `vk_pipeline fetch` 同步；
- `vk_doctor` 新增 `ytdlpMode: binary | module | missing`。

### ② 引导给准：按平台给命令

`vk_doctor` 输出新增 `installPlan`，只回显、不执行：

| 系统 | yt-dlp | ffmpeg |
|---|---|---|
| Windows | `winget install --id yt-dlp.yt-dlp -e` / `pip install -U yt-dlp` / `pipx install yt-dlp` | `winget install --id Gyan.FFmpeg -e` |
| macOS | `brew install yt-dlp` / `pipx install yt-dlp` | `brew install ffmpeg` |
| Linux | `pipx install yt-dlp` / `pip install --user -U yt-dlp` | `sudo apt install -y ffmpeg` |

`faster-whisper` 也带一条，并附注：国内建议 `HF_ENDPOINT=https://hf-mirror.com`。

## 为什么不做自动安装

- **安装期跑不了脚本**：插件按 `github:` 安装是 git 包，pnpm 默认阻断 `prepare`/`postinstall`，除非用户手写 `allowBuilds`。
- **运行期静默装风险高**：要写 `~/.local/bin` 或系统目录（Windows 可能触发 UAC），三个平台命令各不相同，装到一半失败会留下半残环境。
- 插件的链本身有「0 副作用早停」的约定，静默装二进制与之冲突。

装完**不用重装插件**；仍不在 PATH 就用 `VK_YTDLP` 指路径，或直接吃模块兜底。

## 冒烟
