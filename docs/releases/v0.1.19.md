# v0.1.19 — 换了学科也要能判：字幕审计去学科化 + ASR 修复闭环

> 触发这次修复的是朋友拿**高数课**试插件：17 个分 P、996 分钟，P1/P2 抽到电竞采访、P5 空、只有 P10/P17 是真的。插件"能跑通"，但串台检测写死成中国近现代史的关键词，换学科就失灵；失败时还会静默判 ok。

## 修了什么

### 1. 串台判据不再写死学科（核心）

**原来**：`AUDIT_KEYWORDS` 是《中国近现代史纲要》1–10 章的关键词表；分 P 标题里取不到"第 N 章"或 N>10 时关键词为空，直接判 ok。

**现在**（`pipeline/vk_audit.py`）：

- **标题锚点**：从视频总标题 + 分 P 标题自动抽 2–4 字词/bigram，统计该分 P 字幕的覆盖率；
- **跨分 P 相似度**：每个分 P 与其余分 P 的 4-gram IDF 余弦相似度取**中位数**——同一支错轨被复制到多个分 P 时，中位数不会被"错误分 P 互相相似"拉高；
- 两个信号都异常才 `mismatch`，一个异常 `review`，没有数据/无法判定 `unverified`；
- 仍保留 `--expect "1=函数,极限;2=导数,微分"` 作为人工兜底。

**实测**：真实历史课 10 P、真实离散数学 66 P 全部判 `ok`；把历史课 P1/P2 换成真实 AI 教程/数学课/电竞文案，四处注入全部被判 `mismatch` 且只点名被换的分 P。

### 2. 不再静默判 ok

- `audit` 读不到 `by_p/` 时**直接读 `transcript.jsonl`**，不再因为目录不存在返回空结果 + `ok:true`；
- 没有字幕、分 P 太少、标题抽不出词 → `unverified` + `warning`；
- `audit` 始终 exit 0，由链上 `transcriptGate` 读 `verdict` 决定继续/ASR，避免非 0 让 gate 拿不到数据又退回"静默 ok"；
- `vk_prepare` 输出 `audit` + `warnings`；`vk_run` 报告顶部显示 `⚠ ...建议人工核对`。

### 3. ASR 兜底从"装饰"变成真修复

- 新增 `--merge`：转完用 ASR 轨重建 `transcript.jsonl`，下游 clean 真正吃到新字幕；
- `_find_srts` 改为**来源优先级**：`manual/*_asr.srt` > `subs` 探测轨 > 平台轨。旧逻辑"ai-zh 优先"会把 ASR 重转的 SRT 忽略；
- `--audit`：重建后再校验一次，`$.asr.audit` 直接告诉链"修没修好"；
- ASR 提示词改为从视频标题生成，不再写死历史课；
- 已有 `manual/NN_asr.srt` 的分 P 直接复用，**不加载模型、不要求 ffmpeg**。

### 4. ffmpeg 只在真需要时才是依赖

- `doctor` 的 `missing` 只保留硬缺失（yt-dlp / B 站登录）；ffmpeg、faster-whisper 进 `optionalMissing`，并给出 `asrReady`；
- `envGate` 不再因为没装 ffmpeg 卡死"有字幕的视频"；
- ffmpeg 探测覆盖 `VK_FFMPEG` → PATH → WinGet 包目录（winget 装完 PATH 未刷新也能找到）→ `imageio-ffmpeg` 自带二进制。

### 5. `detectPython` 缓存会随配置失效

旧实现把 `_python` 缓存在闭包里，改了 `pythonPath` 必须重启 DSH。现在缓存键 = 当前 `pythonPath` 配置值，改了立即重新探测。

### 6. 长课分批写

`vk_prepare` 返回 `batches[]`（按 4 个分 P / 4 万字符切，附 `estTokens`），并提示"一次只读一批素材，写完立刻 vk_run"。17 个分 P 的课不会再试图一轮写完。

## 顺带修掉的链上阻断

- `templateParse` 没给 `prompt` 时不再 exit 8 导致主链 bail（`vk_run` 的输入本来就没有 prompt）；
- `probeSubs` 探测失败（没 cookie / 接口抖动）不再算硬失败，符合"只做侦察、不阻断"的声明；
- `doctor --allow-cached` 时，登录过期不再阻断本地缓存复用。

## 验证

- `node scripts/smoke.mjs`：全部通过（含新增的跨学科 fixture：5 分 P 高数课，P2/P3 换成电竞解说）；
- 真实历史课 10 P / 离散数学 66 P：audit 全 `ok`，零误伤；
- 4 组真实跨学科注入：全部 `mismatch` 且只点名被替换的 P；
- 端到端：坏 P1/P2 → audit mismatch → ASR（复用已有 SRT）→ 重建 transcript → audit ok → 10 张卡 quality ok。
