# Release v0.1.13 · 成书子链

> 给 `v0.1.13` 用（也可用 `v0.1.12` 的信号节点说明，二者可合并成一条 release）。

## 这一版解决什么

**把「知识卡 → 一本参考书」这条路固化进链里。** 之前插件只做到卡片落库；两本实书（115 页 / 120 页）是靠一次性脚本拼出来的。这一版把它收成子链，且有两条硬规则：

- **两遍排版**：第一遍目录留占位（行数与真实条目一致）→ 转 PDF 量出每个标题的真实页码 → 第二遍填进去。实测 46 个标题、120 页，复测页码差异 **0**。
- **依赖降级**：缺 `python-docx` 报 `BOOK_DEPS_MISSING` 并给安装提示；找不到 PDF 转换器则 PDF 记 `skipped`，DOCX 照常交付。

## 新增

| 文件 | 作用 |
|---|---|
| `pipeline/assemble_book.py` | 简介 + 各编 + 各附录 → `book_all.md`（`utf-8-sig`，容忍 BOM） |
| `pipeline/build_book.py` | Markdown → DOCX（A4／宋体黑体／三级标题／表格／引文块；支持 `--toc`） |
| `pipeline/measure_toc.py` | 从 PDF 按字号定位标题页码（避开目录页同名文字） |
| `pipeline/book_pdf.py` | DOCX → PDF（LibreOffice Kit 或 soffice；缺则 skip） |
| `engine/chains/…/gen.video-to-knowledge.book.json` | 成书子链：7 个节点 |

主链接线：`bookPlan → bookGate（template.deliverable == book）→ bookBuild`。

## 同批的 v0.1.12（信号节点）

- `probe`：多轮采样 B 站 `player/v2`，按分 P 时长择优——该接口同一分 P 多轮结果不同，实测 2–8 轮才拿全。
- `audit`：内容级校验。**只比时长拦不住串台**：实测混入过另一支 22 分钟的 iPhone 评测（覆盖率校验全绿放行）与一段靶场 vlog；现在按章关键词命中 + 异物词判定。
- `asr`：无字幕/串台的兜底转写；音频只落临时目录、转完即删；解码走 ffmpeg→numpy，绕开 faster-whisper 内部 PyAV 的 `TypeError`。
- `template`：识别「把这个视频…沉淀成知识卡，并整合成一本参考书（简介+目录+正文+附录）」这套提示词。
- `bookplan`：只给编/章骨架，正文一个字不代写。

## 冒烟

`npm test`：**80 项全过**（0.1.11 时为 44 项）。新增断言覆盖：五个信号节点存在、信号接线正确、gate 含内容判据、成书子链 6 个节点与两遍排版参数、依赖降级关键字。

## 已知边界

- 成书只负责**版式**，正文必须由模型写进 `book/parts/*.md`；`bookplan` 不生成任何正文。
- 目录页码以本仓排版的 PDF 为准；在 Word 里重排会变。
- 平台字幕串台无法从接口层根治，只能靠 `audit` 拦；拦下后走 `asr`。
