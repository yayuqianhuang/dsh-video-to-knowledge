# AJTC 记忆层（模板）

本目录是插件的**通用记忆层模板**——**默认不含任何用户项目记忆**，仅提供结构与说明。你（或你的 agent）可在此按需沉淀自己的资产。

## 默认铁律（SSOT）

通用治理铁律注册表位于：

```
engine/chains/governance/iron-laws.json
```

它作为**默认参考**随插件分发。你不必沿用它：

- 可以让 agent 在你的项目里**自行建立一套铁律系统**（新增 / 修订铁律会写回该文件，或你指定的位置）；
- 也可以在 `iron-laws.json` 基础上只保留与你相关的几条。

铁律必须经链 / fn 节点 operationalize 为**机械闸门**才真正生效（见 `L-GOV-001`）。

## 资产登记（仅模板）

`asset-registry.md` 在本插件中**仅作为模板存在**（`asset-registry.template.md`）。

- 你可以选择「仅保存模板」（不填任何真实数据），也可以填入自己的资产登记；
- 易变事实（服务器 / 域名 / ICP / 分支 / WIP）建议集中登记在此处，供链运行时 `ajtc_recall_memory` 召回，避免凭记忆拼写错误；
- 若涉及真实凭据或隐私，公开发布插件前请自查脱敏。

## 召回

`ajtc_recall_memory` 工具会扫描本目录，以及 `engine/chains/governance/iron-laws.json`，按关键词返回命中片段。

## 不随插件分发的内容

每日开发日志、过程性记忆、真实项目数据**不**随插件打包。如需本地沉淀，自行在此目录维护即可。
