# 资产登记（模板）

> 本文件是**模板**。你可以：
> - **仅保留模板**（不填任何真实数据），或
> - 填入你自己项目的资产登记（服务器 / 域名 / ICP / 分支 / WIP 等易变事实）。
>
> 登记后可供 `ajtc_recall_memory` 按关键词召回，避免凭记忆拼写错误。
> 公开发布插件前，请自查脱敏（密钥、私人路径、内部 IP 等勿入此文件）。
> 涉及大量日志/过程细节的资产，建议另置子目录，不随插件分发。
